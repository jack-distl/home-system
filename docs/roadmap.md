# Roadmap

What's built (v0.1):
- week and month calendar
- two-way Google and iCloud/CalDAV sync
- lists
- art mode with public-domain paintings or your own images
- weather
- night-time screen off
- on-screen keyboard
- phone layout
- nightly auto-update
- backups

Ideas, roughly in order of usefulness. They're closest to what Skylight charges a subscription for.

- [ ] **Chores with people and stars.** Assign a list item to a person, repeat it daily or weekly, and show a tally per person.
- [ ] **Meal planner.** A week grid (Mon–Sun × dinner) that can push ingredients to the Shopping list.
- [ ] **Day view with a time grid.** For busy days, to see overlaps.
- [ ] **Photo mode.** Mix family photos from a shared iCloud/Google album into art mode.
- [ ] **Remote access to lists.** Via Tailscale (free), so phones can add to the shopping list away from home.
- [ ] **Offline write queue.** If the internet is down, queue edits and push them when it's back.
- [ ] **Settings PIN.** Stop little fingers disconnecting calendars.
- [ ] **Outlook / Microsoft 365** calendars (Microsoft Graph).
- [ ] **Motion sensor wake.** A cheap PIR sensor on the Pi's GPIO pins switches from art to planner as you walk up.
- [ ] **Countdowns.** "12 days until holidays."
